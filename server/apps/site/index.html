FAQ

常见问题

关于软件定位、数据存储与更新机制的简要说明。

ProxySplit 是 VPN 或翻墙软件吗？+

不是。ProxySplit 不提供 VPN、代理节点、订阅或跨境网络服务，只是一款本地应用流量管理与网络调试工具。

软件会上传我的节点和规则吗？+

不会。节点、订阅、应用规则和配置默认保存在本机。商业授权服务只处理账号、设备摘要、授权状态等必要数据。

自动更新如何保证安全？+

客户端只接受官方更新接口返回的 HTTPS 下载地址，并同时验证独立 Ed25519 发布签名和 SHA256 文件摘要；任何一项不匹配都会终止升级。

支持哪些系统？+

当前正式版面向 64 位 Windows 10 与 Windows 11。软件为便携式单文件版本，配置存放在当前 Windows 用户目录。
