# 界面审计与整合（2026-10，分支 feat/reset-center-ui）

## 审计：页面与入口清单（整合前）
| 页面 | 内容 |
|---|---|
| 概览 | 连接大开关、AI 环境卡（仅 aigw 客户）、常用操作（添加节点 / 添加应用 / 全部测速 / 网络诊断→日志）、节点健康、应用摘要、最新日志 |
| 节点 | 节点表、导入、测速、每节点内核选择、分享 |
| 应用分流 | 分流模式、未列出应用线路、应用规则表（含「清空规则」）、导入导出、监测 |

| 设置 | AI 劫持、环境配置、AI 控制、Claude Code 加速、内核与更新（软件更新 + 内核更新 + 自动更新内核 + 日志级别 + 日志上传说明）、分流引擎、系统集成（代理范围、禁用的「系统代理」开关、局域网、自启、托盘、主题）、备份与重置 |

## 发现的问题
1. **重置分散 / 缺失**：只有「备份与重置」里一个整体重置；缓存、残留系统代理、残留进程、规则库、节点内核都没有清除入口，应用规则清空藏在应用页。
2. **一个分节塞多种职责**：「内核与更新」同时管软件更新、内核、日志级别、日志上传；「系统集成」混着网络接管与外观。
3. **接管相关设置拆两处**：代理范围在「系统集成」，接管方式与引擎开关在「分流引擎」。
4. **死控件**：「系统代理」开关永远禁用，只为写一句说明。
5. **AI 控制接口**放在「AI 功能」里，实际是诊断 / 控制用的本机接口。
6. 命名不一致：「账户与设备」vs 菜单「账号」；「分流引擎」vs 应用页「分流模式」。
7. 概览与设置都放 AI 环境面板：概览是给 aigw 客户的摘要卡，设置「AI 劫持」是唯一可「恢复」的位置——保留两处但职责不同（不算重复）。全部测速在概览和节点页各一个按钮，概览是快捷入口，保留。

## 整合结果
设置分节改为：**常规 / 网络与接管 / 内核与节点 / 规则 / AI 功能（AI 劫持、环境配置、Claude Code 加速）/ 账号与设备 / 维护（诊断、AI 控制接口、清除与重置）**。
- 常规：自启、托盘、主题、软件版本 + 检查更新（软件更新唯一入口）。
- 网络与接管：代理范围 + 接管方式 + 推流直连 + 四个建议开关 + 局域网共享（合并原「系统集成」「分流引擎」，删掉禁用的系统代理开关，说明并入代理范围提示）。
- 内核与节点：内核版本、更新内核、自动更新内核；节点内核入口链到节点页 / 清除与重置。
- 规则：只放入口（分流规则页、应用分流页、清除与重置），不在设置里另改一份。
- 诊断：日志级别、日志上传说明、去日志页、去清除与重置。
- **清除与重置**：所有清缓存 / 修网络 / 配置重置 + 配置导出导入 + 撤销上次重置；托盘菜单「清除与重置…」和诊断 / 规则 / 内核分节都链到这里。AI 劫持只显示说明行并跳到「AI 劫持」。
- 跳转统一用 `openSettings(<分节 id>)`（app/nav.ts），设置页 `useSectionJump` 滚过去。
- 删除文件：settings/backup-section、system-section、engine-section；新增 general / network / diag / rules-link / link-row / reset/*。
