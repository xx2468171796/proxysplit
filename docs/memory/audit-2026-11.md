## 查过、确认不用合并的
- 下载：可续传下载只有 `internal/download`（updater、coreupdate/mirror 都调它）。geoupdate 是规则库的一次性小文件读取（带大小上限、30 秒超时），不是第二个续传实现；mirror.go 里的 Range 是测速探针。
- 「明确拒绝」判断：`license.isDefinitiveRejection`（本站 API 错误码）与 `powervpn.grantRejected`（OAuth invalid_grant）是两个服务端的两套协议，各自包内只有一处。
- 定长比较：`sameToken`（控制令牌）、`helloProofValid`（HMAC）、OAuth state，各自直接用标准库，没有重复的自写助手。
- 结束进程：sing-box 的 `killCoreProcs`（core）与 Xray 的 `KillStrays`（xray）各管一种二进制，筛选条件不同（命令行里的端口目录 / 配置路径前缀），只在启动清扫和「清理残留进程」里用。
- 随机串：`xray.newSecret`、`telemetry.NewUUID`、OAuth PKCE 在各自的叶子包里，各一处。
