# 中转站渠道（AI 编程官网客户）

2026-09-30 起。AI 编程官网（ai.zygskins.cn，aigw）的客户由推广员带来，ProxySplit 对这些客户**不显示作者联系方式**，
免得客户绕过推广员直接找作者。ProxySplit 自己的官网 proxysplit.zygskins.cn 和直接注册的用户保持原样。

## 隐藏什么
侧栏的 QQ 群 / 客服微信卡片、官网 / GitHub 图标按钮、启动时的赞赏码弹窗。登录页的 POWER云 按钮改名「用 AI 编程官网账号登录」。

## 怎么认定（任一即可，认定后写进 `%APPDATA%/proxysplit/channel`，退出登录、改文件名、自动更新都不丢）
1. **下载地址**：AI 官网给的是 `/v1/download/proxysplit-ai-latest.exe`（服务器上是 `proxysplit-latest.exe` 的软链，
   `scripts/remote-deploy.sh` 每次发版重建），文件名带 `proxysplit-ai`，客户端首次启动就认出来（`channel.go`）。
2. **账号**：POWER云 `/api/client/me` 返回 `sources`（客户关联的外部站点）；含 `aigw` 时 ProxySplit 服务端把账号
   `users.channel` 记为 `aigw`（迁移 0013，只升不降），登录 / 刷新响应的 `user.channel` 带给客户端。

## 登录路径（没有免登录凭据时）
客户端（中转站渠道）直接打开 POWER云 的 `/api/auth/aigw/start?next=<授权页>`（应用拉起的浏览器请求 Sec-Fetch-Site 是 none，
面板放行；别的网站链过来是 cross-site，仍被拦，防强制登录）→ AI 编程官网登录 → 回到授权页点「授权」→ 回到客户端。
（不在 POWER云 登录页做自动跳转：那样同站跳转会绕过跨站校验。）

## 免登录下载（2026-10-01，v1.9.62）
开通了节点套餐的客户在 AI 编程官网点「下载 ProxySplit」，下载的程序**打开就已登录**（节点、常用程序都加好）：
1. AI 官网 `POST /api/me/proxysplit/download` → 向 POWER云 合作方接口 `POST /api/partner/aigw/users/<id>/client-ticket` 要一枚
   **一次性、3 天**的凭据（32 字节 base64url，43 位；只签给已关联 POWER云 的客户，服务器上签的临时会话不给）；
2. 跳到 `/v1/download/proxysplit-ai-latest.exe?t=<凭据>` → API 302 到 `/download/proxysplit-ai-<凭据>.exe`（下载统计不记凭据）→
   深圳 Nginx 的嵌套 location 把这个名字映射到同一个 `proxysplit-latest.exe`（不写访问日志、no-store）；
3. 客户端启动时（第一次界面快照之前）从自己的文件名取出凭据 → POWER云 `/api/oauth/token`
   `grant_type=urn:powervpn:download-ticket` 换令牌 → 与浏览器登录后完全相同的后续步骤（ProxySplit 登录、会员同步、预置程序、节点订阅）。
   试过的凭据只在 `%APPDATA%/proxysplit/download-ticket` 记哈希，之后不再试；已登录、凭据过期 / 用过、网络失败 → 退回登录页按钮。
没关联 POWER云、POWER云 出错、没配合作方接口时，AI 官网给普通下载地址，下载永远不失败。

## 交付：先开会员
客户还没打开过客户端时，管理员可以先建好关联账号再发会员：
1. `POST /v1/admin/users/powervpn {externalId: <POWER云 客户 id>, channel: "aigw"}` → 返回 ProxySplit 用户（`pv_<id 前 8 位>`）；
2. `POST /v1/admin/users/<id>/grant {planId, durationDays}`。

客户之后用 AI 官网账号经 POWER云 登录，就是这个号。后台用户列表「登录方式」一栏标「中转站」。

## 会员跟 AI 套餐走（2026-09-30）
- POWER云 `/api/client/me` 给 `aiPlanExpiresAt`（客户「AI 代理套餐」即 plan.ai_only 的最晚到期）。ProxySplit 服务端为该用户维护**单独一行** `licenses.source='aigw'`（普通会员，3 台设备），到期时间 = 它：AI 续费就延长，AI 到期就结束在当下（留账不删）。不和自购 / 兑换 / 后台发的会员合并——AI 到期只有这一行到期，客户要继续用就在客户端「会员中心」单独开通。
- 同步时机：POWER云 登录时（在发试用之前，有 AI 套餐就不占这台电脑的一次试用）；客户端启动 20 秒后和之后每 3 小时 `POST /v1/auth/powervpn/sync {accessToken}`（令牌对应的 POWER云 账号必须就是这个用户关联的，否则 403）。客户端每分钟的租约刷新会把新的会员状态带到本机，到期即停代理、回到会员中心。
- 老面板不给 `aiPlanExpiresAt`（字段缺失）时不动会员；给 `null` = 没有 AI 套餐 → 结束 aigw 那一行。
- 中转站客户第一次 POWER云 登录、应用分流还是空的：预置 chrome.exe / msedge.exe / claude.exe / codex.exe / Code.exe / Cursor.exe（规则分流、活动节点），节点订阅本来就自动加，客户点「启动」即可。
