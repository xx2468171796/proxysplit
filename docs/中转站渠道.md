# 中转站渠道（AI 编程官网客户）

2026-09-30 起。AI 编程官网（ai.zygskins.cn，aigw）的客户由推广员带来，ProxySplit 对这些客户**不显示作者联系方式**，
免得客户绕过推广员直接找作者。ProxySplit 自己的官网 proxysplit.zygskins.cn 和直接注册的用户保持原样。

## 隐藏什么
侧栏的 QQ 群 / 客服微信卡片、官网 / GitHub 图标按钮、启动时的赞赏码弹窗。登录页的 POWER云 按钮改名「用 AI 编程官网账号登录」。

## 怎么认定（任一即可，认定后写进 `%APPDATA%/proxysplit/channel`，退出登录、改文件名、自动更新都不丢）
1. **下载地址**：AI 官网给的是 `/v1/download/proxysplit-ai-latest.exe`（服务器上是 `proxysplit-latest.exe` 的软链，
   `scripts/remote-deploy.sh` 每次发版重建），文件名带 `proxysplit-ai`，客户端首次启动就认出来（`channel.go`）。
2. **账号**：POWER云 `/api/client/me` 返回 `sources`（客户关联的外部站点）；含 `aigw` 时 ProxySplit 服务端把账号
   `users.channel` 记为 `aigw`（迁移 0013，只升不降），登录 / 刷新响应的 `user.channel` 带给客户端。

## 登录路径
客户端（中转站渠道）打开的授权地址带 `via=aigw` → POWER云 登录页直接转去 AI 编程官网登录 → 回到授权页点「授权」→ 回到客户端。

## 交付：先开会员
客户还没打开过客户端时，管理员可以先建好关联账号再发会员：
1. `POST /v1/admin/users/powervpn {externalId: <POWER云 客户 id>, channel: "aigw"}` → 返回 ProxySplit 用户（`pv_<id 前 8 位>`）；
2. `POST /v1/admin/users/<id>/grant {planId, durationDays}`。

客户之后用 AI 官网账号经 POWER云 登录，就是这个号。后台用户列表「登录方式」一栏标「中转站」。
